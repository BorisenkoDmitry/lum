# Люм

Отдельный шаблон стоматологического сайта на Next.js App Router, React и Three.js. «Люм» — вымышленное название клиники.

## Запуск

Нужен Node.js 20.9 или новее.

```sh
npm ci
npm run dev
```

Сайт доступен по адресу `http://127.0.0.1:3000`.

```sh
npm run build
npm start
```

## Развёртывание в Docker

Публичный адрес — [lum.dmitriy-borisenko.ru](https://lum.dmitriy-borisenko.ru/). Docker собирает Next.js в режиме standalone. Compose подключает контейнер к существующей сети `coolify`, а Traefik обслуживает домен и сертификат Let's Encrypt.

На сервере из каталога релиза выполните:

```sh
docker compose up -d --build --wait
```

Для привязки образа к релизу задайте `LUM_IMAGE_TAG` с хешем коммита. Если меняете домен, обновите правила Traefik и `NEXT_PUBLIC_SITE_URL` в `compose.yaml` до сборки.

## Настройка

Название, подпись, ссылка для записи и каталог находятся в `components/clinic.js`. Заголовок вкладки задан в `app/layout.jsx`, палитра и вёрстка — в `app/globals.css`.

Форма зуба и два корня создаются программно в `components/tooth-geometry.js`. Генератор `node scripts/generate-tooth.mjs` заранее сохраняет индексированную геометрию в `public/models/tooth.bin` (7136 вершин, 399584 байта). Браузер загружает готовую геометрию через `components/tooth-model.js` и не вычисляет миллион точек при открытии страницы. Материал эмали, отражения и управление вращением находятся в `components/ToothScene.jsx`.

Движение мыши слегка поворачивает зуб. Зажатая левая кнопка мыши или перетаскивание пальцем позволяют свободно осматривать зуб сверху, снизу и с обратной стороны. Выбранный ракурс сохраняется после отпускания. Кнопка со стрелкой возвращает исходный ракурс. Клавиши со стрелками после фокусировки сцены управляют небольшим поворотом. Режим уменьшенного движения отключает автоматическую реакцию на курсор, сохраняя ручное вращение.

Полноэкранное меню содержит поиск, раскрывающиеся группы и краткие описания услуг. Ссылка для записи появится, когда `bookingUrl` будет задан в настройках клиники.

Каталог объединён в восемь направлений по мотивам стоматологических разделов «Альтамед+». Поиск учитывает сокращения, разговорные названия и названия технологий. Данные каталога можно заменить под конкретную клинику.

Учебный цикл на поверхности зуба показывает налёт и очищение, линию трещины и условную реставрацию, изменение оттенка и осветление. Эффекты заданы в `components/enamel-material.js`, последовательность — в `components/ToothScene.jsx`. Кнопка паузы останавливает цикл. При открытом каталоге, в скрытой вкладке и при системном уменьшении движения автоматическая анимация приостанавливается.

Белые контуры фона заданы компактной SVG-маской `public/dental-contours.svg`.

После главного экрана расположены услуги, вымышленные врачи, отзывы, форма заявки и вопросы перед приёмом. Заголовок услуг, текст и девять услуг с ценами перенесены из предоставленных скриншотов. Данные услуг находятся в `components/clinic.js`, иллюстрации и вёрстка — в `components/HomeSections.jsx` и `app/home-sections.css`.

Русская версия доступна на `/`, английская на `/en`. Обе страницы статически рендерятся с правильным html lang, отдельными title/description/canonical и hreflang. Переключатель RU/EN находится справа в шапке. UI-переводы — `components/messages.js`, каталог и описания — `components/clinic-translations.js`. Для размещения задайте `NEXT_PUBLIC_SITE_URL` перед сборкой.

Hero использует локальный Unbounded 600/700 с кириллицей и латиницей. Заголовок «Стоматология для всей семьи» и текст перечисляют основные направления лечения без вымышленных адресов. Шрифт и размеры — `app/hero-typography.css`.

Отзывы и форма на двух языках находятся в `components/ReviewsAndBooking.jsx`. Отзывы переключаются стрелками и кнопками авторов, все истории вымышлены и отмечены как демонстрационные. Форма проверяет имя и телефон, показывает результат заполнения и не отправляет, не хранит и не логирует персональные данные. Отправку в клинику необходимо подключить отдельно. Запись из карточки врача прокручивает страницу к форме и переводит фокус в имя.

Сначала показывается `public/tooth-preview.webp` (8650 байт). Один общий слой перемещается из главного экрана в центральный слот услуг через `components/SharedToothStage.jsx`. После загрузки страницы и паузы 900 мс 3D запускается в свободное время браузера. Автозапуск разрешён только при достаточной памяти/числе потоков, без экономии трафика и при WebGL 2 без major performance caveat. При 4 ГБ памяти или менее, 4 потоках или менее, 2G, Save-Data остаётся картинка. Это консервативная оценка устройства. При устойчивой частоте ниже 20 кадров/с активная сцена возвращается к WebP. Картинка сохраняет ту же траекторию между блоками. При уменьшенном движении перенос выполняется без плавной траектории, 3D автоматически не запускается.

Масштабирование внешнего слоя сохраняет WebGL-контекст и ручной ракурс. Canvas использует offsetSize при измерении, чтобы CSS scale не учитывался повторно. Размеры слотов измеряются при изменении экрана и загрузке шрифтов. Плотность рендеринга ограничена 1,35, отражения используют карту 64×64. В скрытой вкладке и вне экрана автоматический цикл останавливается.

Все девять иллюстраций услуг созданы встроенным image_gen и сохранены как `public/services/{checkup,osstem,implant-former,crowns,veneers,caries,extraction,hygiene,braces}.webp` с прозрачностью. Их точные промпты находятся в `public/services/generation-prompts.json`. Каждый WebP весит 17–36 КБ. Карточки идут круговым слайдером, по две слева и справа от зуба.

Секция врачей находится в `components/DoctorsSection.jsx` и `app/doctors.css`. Имена, фотографии и биографии вымышлены. Портреты созданы встроенным image_gen и сохранены в `public/doctors/alexander.webp`, `public/doctors/mikhail.webp`, `public/doctors/anna.webp`. Точные промпты сохранены в `public/doctors/generation-prompts.json`. Для изображений используется Next Image с отложенной загрузкой. Параллакс курсора и прокрутки действует на устройствах с мышью и отключается при уменьшенном движении.

Поэкранные переходы, блокировка повторного жеста во время перехода и появление элементов реализованы в `components/SectionTransitions.jsx` через GSAP Observer и ScrollToPlugin. Для длинных секций предусмотрены промежуточные позиции прокрутки. При уменьшенном движении действует обычная прокрутка. Вращение зуба и открытое меню обрабатывают касания самостоятельно.
